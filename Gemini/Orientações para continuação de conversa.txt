Resumo do Projeto: Central de Conhecimento — Suporte Cloud (RM)
1. Visão Geral e Arquitetura do Sistema
Objetivo: Plataforma web interna para consulta instantânea de documentações operacionais e resoluções de erros do Suporte Cloud (RM).

Stack Tecnológico:

Frontend: Vanilla JavaScript, CSS customizado e HTML5 (sem frameworks pesados).

Motor de Busca: Fuse.js (fuzzy search / extended search) integrado a um algoritmo personalizado de pontuação de relevância.

Processamento de Imagem (OCR): Tesseract.js para leitura automática de textos em prints colados (Ctrl+V) ou anexados.

Fonte de Dados: API do Notion integrando recursivamente páginas e subpáginas.

Hospedagem & Deploy: GitHub integrado com deploy automático no Netlify.

Criação de Assets Locais: Scripts Node.js para varredura e download persistente de imagens.

2. Funcionamento do Backend/Sincronização (fetch-notion.mjs)
Download de Imagens Persistentes (/assets): Como as URLs de imagens do S3/Notion expiram em 1 hora (X-Amz-Expires=3600), o script Node.js faz o download local automático de todas as imagens para a pasta ./assets/ durante a varredura, atribuindo nomes únicos (ex: img_[block_id].png).

Tratamento de Links e Menções:

Converte rich_texts com t.href e menções de páginas do Notion para a sintaxe Markdown [Texto](URL).

Preserva a hierarquia de páginas (path completo usando delimitadores >) para exibição do breadcrumb.

Saída de Dados: Gera os arquivos docs.json e docs.js (este último exportando o objeto global const DATA = ... para consumo direto no frontend sem requisições HTTP adicionais).

3. Frontend e Algoritmo de Busca (index.html)
Autenticação Simples: Prompt de senha local armazenada em sessionStorage (SENHA_CORRETA = "redondo").

Algoritmo de Relevância (getScore):

Sloppy Match / Proximidade: Regex avançado que tolera conectivos e pequenas distâncias entre palavras para encontrar frases inteiras acentuadas ou não.

Pesos Direcionados: Premia acertos exatos no Título, Caminho e Texto. Dá bônus exponencial se múltiplos termos da busca forem encontrados no mesmo documento (evitando que documentos com apenas 1 palavra genérica atropelem o resultado).

Stopwords expandidas: Filtro em português e inglês para impedir que parâmetros de URLs (http/https) e palavras como and, please, that, is inflem resultados.

Interface & UX:

Balões de Conteúdo (.snippet): Fundo escuro translúcido (rgba(4, 8, 16, 0.55)), borda azul vibrante (rgba(90, 167, 255, 0.25)), altura máxima fixa de 500px com rolagem interna e captura de até 1700 caracteres ao redor do termo encontrado.

Miniaturas de Imagens: Exibidas dentro do balão com max-width: 280px e max-height: 180px.

Modal de Zoom: Clique na miniatura abre modal em tela cheia com fundo desfocado (backdrop-filter: blur).

Highlights (<mark>): Marcação em azul neon translúcido (#5aa7ff) tolerante a acentuação para destacar termos correspondentes.

Modal de Feedback: Envio de sugestões/correções integrado via Webhook para planilha do Google Sheets.
